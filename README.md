# rutinless-v2

> **Task and Routine Management (Oba).**

rutinless-v2 (Oba) is a routine and task management application focused on efficiency and "rutin-less" (routine-less) dynamic workflows.

## 🚀 Features
- **Dynamic Scheduling**: Adaptable routine management.
- **Task Tracking**: Efficient task updates.

## 🛠️ Tech Stack
- **Language**: TypeScript
- **Framework**: Next.js (Inferred)

## 📦 Installation

```bash
pnpm install
```

## 💻 Usage

```bash
pnpm dev
```
